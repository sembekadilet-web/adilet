Анашым, туған күніңізбен!

Анаңызға арналған қазақ тіліндегі жүрекжарды туған күн құттықтауы. Хатты ашқанда гүлдер жауады, басып ашылатын тілектер мен шырағын өшіруге болатын шағын торт тосынсыйы бар. Сайт сыртқы кітапханасыз жұмыс істейді.

## Іске қосу

1. Осы буманы VS Code-та ашыңыз.
2. VS Code терминалынан бетті әдепкі браузерде ашыңыз:

   ```powershell
   Start-Process .\index.html
   ```

Сайтқа жергілікті сервер арқылы кіргіңіз келсе, Python орнатылғанда:

```powershell
python -m http.server 8000
```

Содан кейін браузерден [http://localhost:8000](http://localhost:8000) мекенжайына өтіңіз.

Құттықтау мәтінін және арнау атауын `index.html` ішінен тікелей өзгерте аласыз.
